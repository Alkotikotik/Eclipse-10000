Format of 32-bit instructions 64bit lower

R-Type (Standard ALU & System)
[31:26]  Opcode     (6 bits)
[25:18]  rx0        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[17:10]  rx1        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[9:0]   Unsigned immediate      (10 bits)

B-Type (3 operand ALU, only add, sub, mul)
[31:26]  Opcode     (6 bits)
[25:18]  rx0        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[17:10]  rx1        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[9:2]    rx2        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[1:0]    imm2       (don't laugh)

I-Type (Immediate Operations & STR, LDR)
[31:26]  Opcode     (6 bits)
[25:18]  rx0        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[17:10]  rx1        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[9:0]   Signed Immediate  (10 bits: Signed offset / Constant)

S-Type (SPR operations)
[31:26] Opcode (6)
[25:18] rx0    (8)
[17:16] SPR_Sel(2)   00=SP  01=LR  10=GP  11=reserved
[15:0]  Immediate(16, signed)

L-Type (LOAD)
[31:26] Opcode
[25:18] rx0
[17:0] signed immediate (18 bits)

J-Type (Massive Load / Direct Jumps)
[31:26]  Opcode     (6 bits)
[25:0]   Immediate  (26 bits: Imm26)

//Register
Registers are fragmented, visual representation is in Fragmentation.svg file.
Shortly, each 32-bit rx register is fragmented into 2 16-bit ry register and they are fragmented into 2 8-bit rz registers, thus each 32-bit register fragmented into 4 8-bit registers. Though note: they are the same register but the different parts of it.
Accessing them:
rx21 full rx21 register
ry211 higher 16bits of rx21
rz212 mid-high 8 bits of rx21

//VRAM & Screen
There is dedicated 1MB of VRAM at 04000000 - 0x040FFFFF, the screen resolution is 480p. The pixel format is standard RGBA4444, taking up exactly 2bytes or u16

By default stack lives at 0x03FFFFF0
//Opcodes
ALU Instructions (R-Type)
000100 : MOV    rx0, rx1
001101 : HIMUL  rx0, (rx1 + imm10) //imm10 Unsigned, might very well be 0
000010 : XOR    rx0, (rx1 + imm10) (rx0 = rx0 XOR (rx1 + imm10))
000110 : OR     rx0, (rx1 + imm10)
001110 : AND    rx0, (rx1 + imm10)
001111 : NOT    rx0  (    + imm10)
001000 : SHL    rx0, (rx1 + imm10)
001100 : SHR    rx0, (rx1 + imm10)
001010 : SRA    rx0, (rx1 + imm10)

ALU Instructions (B-Type)
//The imm2 is made specifically for "for loops" it supports +1, +2 and -1
000001 : ADD    rx0, rx1, rx2 +- imm2 rx0 = rx1 + (rx2 +- imm2)
000011 : SUB    rx0, rx1, rx2 +- imm2
000111 : LOMUL  rx0, rx1, rx2 +- imm2
000101 : DIV    rx0, rx1, rx2 +- imm2
001011 : MOD    rx0, rx1, rx2 +- imm2
001001 : SDIV   rx0, rx1, rx2 +- imm2

Memory Instructions
010001 : LOAD   rx0, imm18             //Loads imm into rx0
100011 : LDR    rx0, (rx1 +- imm10)  // Load from memory
100111 : STR    rx0, (rx1 +- imm10) // Store rx0 at location specified by (rx1 +-imm10)

Stack manipulations (L-Type)
100100 : PUSH rx0
100101 : POP rx0

Special type operations (S-Type)
101000 : SPRLDR rx0, (SPR +- imm16)     // Load rx0 to SPR +- imm16
101001 : SPRSTR rx0, (SPR +- imm16)    // Store at rx0 from SPR+-imm16
101010 : SPRSET rx0, SPR              // SPR = rx0
101011 : SPRADD rx0, SPR, imm16      // SPR = rx0 + imm16
101100 : SPRSUB rx0, SPR, imm16     // SPR = rx0 - imm16
101101 : SPRLEA rx0, SPR, imm16    // rx0 = location of selected SPR

Jumps & Subroutines
111111 : JMP imm26        // Unconditional Jump to imm26 address/label
110111 : JR rx0          // Unconditional Jump to rx0
111000 : CALL imm26     // Save PC+4 to LR and Jump to imm26 address
010000 : RET           // Return from subroutine (PC = LR)

Privilege and Syscalls
010010 : SYS             // System Call Exception
111101 : RETU           // Return to User Mode from Exception


Format of 64-bit instructions
Split in 2 words, first word is essentially same as regular 32-bit instructions, but [9:4] is sub-op indicating 64bit operation
G-type (General) <<==
First word:
[31:26] 000000 (escape opcode to 64-bit instructions)
[25:18] rx0        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[17:10] rx1        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[9:4]   sub-op     (6-bit opcode indicating 64-bit instruction)
[3:0]   spare
Second word:
[31:0]  really instruction dependent, doesn't fit into individual types
==>>

Loads:
[31:0] imm32
010001 : LMA //Load MASSIVE 32bits in one instruction

X-type (STX/LDX) <<==
First word:
[31:26] 000000 (escape opcode to 64-bit instructions)
[25:18] rx0
[17:13] rb1    (register base, only full registers can be used)
[12:10] imm[28:26]
[9:4]   sub-op
[3:0]   imm[25:22]
Second word:
[31:24] rx2    (index selector)
[23:22] scale  (0-3)
[21:0]  imm[21:0]

STX/LDX
010000 : STX rx0 >-> [rx1, rx2 << val + addr] <-< //Stores rx0 at rx1 + ((rx2 << val) + addr)
011111 : LDX rx0 <-< [rx1, rx2 << val + addr] >->

Fused CMP and branch, separated into pure register and pure immediate forms, in order to avoid useless wait for ALU in pure register form
Register Form <<==
First word:
[31:26] 110000 (escape opcode to 64-bit instructions)
[25:18] rx0        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[17:10] rx1        (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[9:5]   sub-op     (6-bit opcode indicating 64-bit instruction)
[4:0]   unused
Second word:
[31:26] unused
[25:0]  imm26 (branch target)
==>>

00001 : BEQ  rx0 <-> rx1 -> imm26 //compares and immediately jumps
00010 : BNE  rx0 <-> rx1 -> imm26
00011 : BGU  rx0 <-> rx1 -> imm26
00100 : BSU  rx0 <-> rx1 -> imm26
00101 : BGS  rx0 <-> rx1 -> imm26
00110 : BSS  rx0 <-> rx1 -> imm26
00111 : BGEU rx0 <-> rx1 -> imm26
01000 : BSEU rx0 <-> rx1 -> imm26
01001 : BGES rx0 <-> rx1 -> imm26
01010 : BSES rx0 <-> rx1 -> imm26

Immediate form <<
First word:
[31:26] 110000 (escape opcode to 64-bit instructions)
[25:18] rx0     (8 bits: 5-bit Reg ID + 3-bit Size/Offset)
[17:10] imm8    (Most significant bits of full imm19)
[9:5]   sub-op  (6-bit opcode indicating 64-bit instruction)
[4:0]   imm5    (Somewhat significant bits of full imm19)
Second word:
[31:26] unused  (Least significant bits of imm19)
[25:0]  imm26 (branch target)
>>

10001 : IBEQ  rx0 <-> imm19 -> imm26
10010 : IBNE  rx0 <-> imm19 -> imm26
10111 : IBGU  rx0 <-> imm19 -> imm26
11000 : UBSU  rx0 <-> imm19 -> imm26
10011 : IBGS  rx0 <-> imm19 -> imm26
10100 : IBSS  rx0 <-> imm19 -> imm26
10101 : IBGES rx0 <-> imm19 -> imm26
10110 : IBSES rx0 <-> imm19 -> imm26
11001 : IBGEU rx0 <-> imm19 -> imm26
11010 : IBSEU rx0 <-> imm19 -> imm26
